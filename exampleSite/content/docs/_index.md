The [PDI API reference](doxygen:index) is generated by docsygen from PDI's XML in
`assets/doxygen/`, in three versions: the latest release, 1.12, at `/docs/latest/`, the
development version, `main`, and an older release, 1.7. Hand-written pages link into it with
`doxygen:` destinations, which go to the latest release unless they name a version, for example:

- [the installation guide](doxygen:Installation);
- the datatype class, [](doxygen:PDI::Datatype);
- the function that shares data with PDI, [](doxygen:PDI_share);
- the same function in 1.7, [](doxygen:1.7/PDI_share).
