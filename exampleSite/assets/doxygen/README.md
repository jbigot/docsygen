# PDI's Doxygen XML

The example site renders three versions of [PDI](https://github.com/pdidev/pdi)'s reference
(`content/docs/_content.gotmpl`). Each directory is Doxygen 1.18.0's XML output, the oracle's
version (`check-docsy.sh` checks it), generated by
`../../generate-pdi-xml.sh PDI_SOURCE_DIR CONFIGURED_DOXYFILE NAME` with PDI's own documentation
configuration, as XML only and with `XML_PROGRAMLISTING=NO`.

The configured Doxyfile comes from a CMake configuration of the tag's `pdi/` directory, with the
documentation on and everything else that can be off turned off:

```sh
cmake -S pdi -B .build-doc -DBUILD_DOCUMENTATION=ON -DBUILD_TESTING=OFF -DBUILD_FORTRAN=OFF \
  -DBUILD_BENCHMARKING=OFF -DBUILD_PYTHON=OFF
```

It writes the Doxyfile and the generated headers that it lists as inputs
(`.build-doc/pdi/export.h` and `version.h`).

| Directory | Version | PDI commit | Configured Doxyfile |
| --- | --- | --- | --- |
| `pdi/` | `main` | 9645c141 (1.12.0-14) | `<build>/pdi/docs/Doxyfile`, from PDI's `ClangDevel` preset |
| `pdi-1.12/` | 1.12, the latest release | 21e86d15 (tag `1.12.0`) | `.build-doc/docs/Doxyfile` (`configure_file`) |
| `pdi-1.7/` | 1.7, an older release | 7eadb531 (tag `1.7.1-gh`) | `.build-doc/docs/Doxyfile.doxygen_doc` (`doxygen_add_docs`) |

## Adjustments for Doxygen 1.18

- None of the three Doxyfiles needed a change. Doxygen 1.18.0 warns that `DOT_MULTI_TARGETS`
  is obsolete, in all three, and ignores it.
- `pdi-1.7/` lacks the Fortran interface. 1.7.1's Doxyfile lists
  `.build-doc/fmoddir/pdif.h`, which only a Fortran build generates, through zpp. The vendored
  zpp 1.0.15 doesn't load with CMake 4, so Doxygen skips that input (and warns).

## Hand edits

Regenerating a directory drops these edits: make them again, each in its own commit.

- `pdi-1.12/`: the page `serialize_plugin` (the Serialize plugin) is removed, so that a page of
  `main` has no twin in the latest release. Its file, its `index.xml` entry, its `innerpage` in
  `Plugins.xml`, and its row of the plugin table in `Plugins.xml` (whose `rows` goes from 11 to
  10) are gone. Every other version has the page, since `main` was 14 commits past 1.12.0 and
  no page of `main` was missing from 1.12.
- None for classes: nine classes of `pdi-1.7/` (`PDI::Config_error` and the other error
  classes) are gone from 1.12, so 1.7 has pages without a twin as it is.
