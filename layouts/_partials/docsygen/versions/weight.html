{{- /* The weight of a version's section, which orders the sections as the version menu (docsygen/versions/order.html) does, as far as a call can tell: the labels that are not releases first, by their weight (default 1, then Hugo orders them by title), then the latest release, then the other releases, newest first, by their first three numbers (each up to 999). A release newer than the latest one comes after it here, since a call can't tell which release is the latest. Provisional (versions with placements). version the label latest whether it is the latest release weight the call's weight option, if any Usage: partial "docsygen/versions/weight.html" (dict "version" "1.7" "latest" false) */ -}} {{- $out := .weight | default 1 -}} {{- if .latest -}} {{- $out = 1000000000 -}} {{- else if findRE `^[0-9]+(\.[0-9]+)*$` .version 1 -}} {{- $n := split .version "." -}} {{- $out = 1000000001 -}} {{- range $i, $scale := slice 1000000 1000 1 -}} {{- $k := 0 -}} {{- /* Without leading zeros, which int reads as octal. */ -}} {{- if lt $i (len $n) -}}{{- $k = int (strings.TrimLeft "0" (index $n $i) | default "0") -}}{{- end -}} {{- $out = add $out (mul $scale (sub 999 (math.Min 999 $k))) -}} {{- end -}} {{- end -}} {{- return int $out -}}
