{{- /* Add the pages of one Doxygen XML directory to a site. Call it from a content adapter in the parent directory of the version roots, once per version: store the content adapter's context, . dir the XML directory, under assets/ version the version's label path the version root, relative to the adapter's directory latest whether this is the latest release, which unversioned links go to (default false): its pages are generated at the sibling latest/ of path, and each one gets an alias at the same place under path, which redirects to it search whether the pages are in the site's search index (default: latest) pathMap rewrites of file locations, [{from, to}] (default []) store, dir, version and path are required; the label latest and a path named latest are reserved for the latest release. The pages of the other versions are left out of the sitemap, since their canonical page is usually in latest/. The version root is titled with the project's name (PROJECT_NAME) and the label, its menu entry is the label (latest (LABEL) for the latest release), and its weight puts the roots in the order of the version menu (docsygen/versions/order.html). A call marked latest also adds a headless page at its numbered path, under its aliases, so that docsygen/versions.html sees it even when another call marked latest wins latest/. Development mode: when the site sets params.docsygen.versions (a list of labels, latest allowed), a call whose label is not in it, unless it is the latest and latest is, adds only a headless root page, so that links to that version can tell it from a misspelt one. The latest version must be built. Usage, in content/docs/_content.gotmpl: {{ partial "docsygen/adapter.html" (dict "store" . "call" $call))) -}} {{- else -}} {{- if $latest -}} {{- $store.AddPage (dict "path" $numbered "kind" "section" "title" .version "build" $headless "params" (dict "toc_hide" true "hide_summary" true $numbered "release" $release "search" $search "call" $call -}} {{- $model := partial "docsygen/model.html" $dir -}} {{- $paths := partial "docsygen/paths.html" (dict "model" $model "pathMap" $pathMap)
