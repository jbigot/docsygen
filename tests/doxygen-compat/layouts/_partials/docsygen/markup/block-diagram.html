A privately inherited base ends its branch. The first row of 8 or more classes is drawn as lists and ends the tree: on the base side in reverse, on the derived side every other class, as Doxygen's DualDirIterator steps by two. A class outside the model, or a reference without a refid (Doxygen links some by name, an XML gap), is a box without an area, whose bases and derived classes are those that name it in their own references; so is a template instance (a reference whose text is not the class's name), which is labelled by that text and has no tooltip: its bases are its template's, its derived classes those that inherit that very instance.
